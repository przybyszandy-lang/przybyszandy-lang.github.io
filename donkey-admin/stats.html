How views are counted

Joke / meme: shown on screen (at least half visible for 1 second) = 1 point.
Video: shown = impression (0 points) · played 3 seconds = 1 point · played to half way = 3 points · played to the end = 5 points. Only the highest level counts (max 5 per video).
Each phone counts each item once per day. Creators' own views currently count too (testing phase; they will be excluded before real payouts).
